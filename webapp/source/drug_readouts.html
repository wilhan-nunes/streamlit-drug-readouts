Drug Readout Analysis

Translate GNPS feature-based molecular-networking annotations into drug exposure readouts. Analysis runs in your browser — uploaded tables and results never leave your machine. You may also retrieve public GNPS2 task results by task ID.

Under development. This portable, single-file app can be downloaded as drug_readouts.html and opened locally to analyze uploaded tables offline. No Python installation or server is needed. Retrieving a GNPS2 task or newer Zenodo metadata requires an internet connection.

Drug metadata: Embedded offline copy

The Zenodo dataset can differ from the built-in copy and change readouts. A successful refresh is cached in this browser for later offline use; it does not rewrite this HTML file. Rerun analysis after switching metadata.

About the input files

Use the GNPS2 FBMN quantification table (featuretable_reformated.csv) and library annotation table (merged_results_with_gnps.tsv). The quantification table needs a row ID column; annotation needs #Scan#, SpectrumID, Compound_Name, MQScore, and SharedPeaks.

🧭 Purpose

This app translates GNPS compound annotations into drug exposure information. It uses standardized pharmacologic vocabularies developed for all drug reference spectra on GNPS. By linking molecular features to pharmacological ontologies, it enables rapid identification of drugs present in your data and provides insight into their properties.

📘 How it works

  1. Download the GNPS Drug Library MGF spectra. The app also works with the default library in an FBMN job, but the drug library increases coverage, especially for drug metabolites.
  2. Run an FBMN job using the GNPS Drug Library MGF file.
  3. Enter the GNPS Feature-Based Molecular Networking task ID and set the analysis parameters above, or upload its two result tables.
  4. The app retrieves and matches compound annotations to entries in a curated drug ontology.
  5. Review the visualizations and customize the annotation table; recalculate results after editing.

🧩 Key features

  • Annotates input feature tables with drug classifications.
  • Maps detected features to pharmacological ontologies across multiple levels.
  • Uses curated vocabularies to support biological and clinical interpretation.

🧪 Example dataset

Select Load example in the input panel to explore the app without preparing your own data.
