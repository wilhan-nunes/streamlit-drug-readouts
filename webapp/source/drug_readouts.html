Drug Readout Analysis

Translate GNPS2 FBMN annotations or Everything Bagel features into drug exposure readouts. Enter a public task ID and the app identifies its workflow from GNPS2 job metadata, or use your own files without a task ID. Analysis runs in your browser; task and Zenodo files are fetched directly by your browser.

About the input files
  • GNPS2 task: public tasks are identified from submission_parameters.yaml before files are loaded. FBMN uses featuretable_reformated.csv and merged_results_with_gnps.tsv. Everything Bagel preparation retrieves aligned_features.csv and aligned_features_filled.mgf; MGF SCANS must match feature table row ID.
  • FBMN tables: the quantification table needs row ID and sample columns containing .mzML or .mzXML; the annotation table needs #Scan#, SpectrumID, Compound_Name, MQScore and SharedPeaks. Both should come from the same FBMN task.
  • Feature table + query MGF: a local library search needs no task ID. It takes a feature table with row ID and .mzML/.mzXML sample columns (for example an EB aligned_features.csv) and a query MGF whose SCANS match those row IDs.

🧭 Purpose

This app translates GNPS compound annotations into drug exposure information. It uses standardized pharmacologic vocabularies developed for all drug reference spectra on GNPS. By linking molecular features to pharmacological ontologies, it enables rapid identification of drugs present in your data and provides insight into their properties.

📘 How it works

  1. For FBMN, enter a task ID with completed library annotations or upload its two result tables.
  2. For library search, enter an Everything Bagel task ID, or skip the task ID and upload a feature table and query MGF. Select Prepare library search files: the browser obtains query spectra from GNPS2 or your files and drug reference spectra from Zenodo, showing download progress.
  3. Once a search engine is installed, run library search and review the mapped drug readouts.
  4. Review the visualizations and customize the annotation table; recalculate results after editing.

🧩 Key features

  • Annotates input feature tables with drug classifications.
  • Maps detected features to pharmacological ontologies across multiple levels.
  • Uses curated vocabularies to support biological and clinical interpretation.
